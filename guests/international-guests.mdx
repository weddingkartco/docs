---
title: "International Guests"
description: Add and message guests outside India
---

Weddingkart supports guests in any country. The process for adding international guests is the same as for local guests — the only requirement is that Weddingkart knows the guest's country code.

## Adding international guests manually

<Steps>
  <Step title="Open the Guests section">
    Navigate to the wedding in the app and open **Guests**.
  </Step>
  <Step title="Tap Add Guest">
    Tap **Add Guest** → **Add Manually**.
  </Step>
  <Step title="Enter the international phone number">
    Enter the guest's name. The phone number field is set to India (+91) by default, so for an international guest either tap the country code next to the number and pick their country, or type the full number starting with `+` and the country code — Weddingkart detects the country automatically.

    | Country | Example format |
    |---------|---------------|
    | United States | `+1 555 123 4567` |
    | United Kingdom | `+44 7911 123456` |
    | UAE | `+971 50 123 4567` |
    | India | `+91 98765 43210` |

    If you type a number without the `+`, it's read as a number in the country currently selected.
  </Step>
  <Step title="Save">
    Tap **Save Guest**. The guest is added with their international number.
  </Step>
</Steps>

## Adding international guests via Excel

For large groups of international guests, include their numbers in your Excel file with the country code in the phone column. Weddingkart reads the country code during import and stores the number in the correct format.

<Tip>
  Always verify international phone numbers before importing. A wrong country code means WhatsApp messages will not be delivered.
</Tip>

## How Weddingkart handles missing country codes

If a phone number in your Excel file has no country code, Weddingkart assumes it's an Indian number (+91). This applies regardless of which country you or your account are in. When adding guests manually, the number is read in whichever country is selected in the country code picker (India by default).

This means:

- If all your guests have Indian numbers, you can safely omit country codes.
- For every non-Indian number, include the `+` country code to avoid incorrect assumptions.

<Warning>
  Do not leave out country codes for international guests in your import. Weddingkart treats every number without one as Indian, which will cause delivery failures for your international guests.
</Warning>

## WhatsApp messaging for international guests

WhatsApp messaging works the same way for international guests — they receive messages in the WhatsApp app they already use, with no additional setup required on their end.

However, WhatsApp charges different rates per message depending on the destination country. Indian guests cost 1 credit per message. International guests may cost more credits depending on their country's WhatsApp rate.

Check the pricing details before sending bulk announcements to international guests.
