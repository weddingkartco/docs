---
title: "Adding Guests"
description: Add guests to your wedding manually or by importing from Excel
---

Open **Guests** and tap **Add Guest** to see every way to add guests:

- **Add Manually** — enter guest details one by one
- **Import from Excel** — upload your guest list spreadsheet (see [Excel Import](/guests/excel-import))
- **Phone Contacts** — pick guests from your phone's contact list
- **Invite via Joining Link** — share a link or QR code so guests add themselves
- **Add Existing Guests** — shown when you're inside a group; adds guests who are already in another group

## Manual addition

Use manual addition when you have a handful of guests to add or need to quickly add a single person.

<Steps>
  <Step title="Open the Guests section">
    Navigate to the wedding in the Weddingkart app and open **Guests**.
  </Step>
  <Step title="Tap Add Guest">
    Tap **Add Guest** → **Add Manually**. The **Create Guest** form opens.
  </Step>
  <Step title="Enter name and phone number">
    Enter the guest's name and phone number. You can add two more numbers in **Alternate Number** and **Alternate Number 2**, for up to three phone numbers per guest.

    The country code is set to India (+91) by default. For international guests, tap the country code next to the number to pick their country, or type the full number starting with `+` (e.g., `+1 555 123 4567` for the US) and the country is detected automatically.
  </Step>
  <Step title="Assign to a group (optional)">
    Use **Select Group** to add the guest to one or more groups. You can skip this and assign groups later. If you don't have any groups yet, tap **Create a group to organize guests**.
  </Step>
  <Step title="Save">
    Tap **Save Guest**. The guest is added to your wedding immediately. To keep going, tap **Save & Add Another** instead — the form clears so you can enter the next guest.
  </Step>
</Steps>

## Adding from phone contacts

Tap **Add Guest** → **Phone Contacts** to pick guests straight from your phone's contact list. This works in the iOS and Android apps only — contact picking isn't available on the web app, so use **Add Manually** or **Import from Excel** there.

## Letting guests add themselves

Tap **Add Guest** → **Invite via Joining Link** to create a link (and QR code) that guests use to add themselves. This is useful for guests whose number you don't have — share the link on family WhatsApp groups, or print the QR on your invite.

- Create a separate link per group — for example, a Reception link adds people straight to your Reception group.
- If a link is set to **Approve each guest**, new sign-ups wait for you to **Approve** or **Decline** them before they're added to your guest list. The **Invite via Joining Link** option shows how many people are waiting.

<Tip>
  Still add at least one number per family yourself so no family is missed.
</Tip>

## Guest fields

Every guest requires a name and at least one phone number. Everything else is optional.

| Field | Required | Notes |
|-------|----------|-------|
| Name | Yes | The name filled in wherever a message uses the guest's name (`{{guest_name}}`) |
| Phone number | Yes | Up to 3 numbers per guest; include country code for international |
| Group | No | Assign on creation or any time afterward |

## Guest attributes

Guest attributes are custom fields you attach to individual guests. They work like extra columns in a spreadsheet — you define the field name once, then set a value per guest.

Common attributes include:

- `hotel_name` — which hotel the guest is staying at
- `pickup_point` — airport or station pickup location
- `bus_number` — shuttle or bus group assignment
- `meal_preference` — dietary requirement

Once you set an attribute, you can use it in any WhatsApp message. While editing a message, tap a chip under **Insert a guest detail** — it adds a placeholder such as `{{hotel_name}}`, and Weddingkart replaces it with each guest's specific hotel name at send time. Every guest gets a personalised message from a single template.

You can add attributes in three ways:

- **In bulk from Excel** — include them as extra columns in your file (see [Excel Import](/guests/excel-import)).
- **Per guest** — open a guest's profile and tap **Add** in the **Per Guest Info** section to enter a label (for example, PNR or Hotel name) and a value.
- **For the whole wedding** — tap **Attributes** on the Guests screen to open **Attribute Management**, where you can add an attribute, set its fallback text, combine two attributes into one, or delete one.

<Note>
  If a guest has no value for an attribute you used, their message shows that attribute's fallback text instead — set it with **Set fallback** in **Attribute Management**. The message preview also tells you when the guest you're previewing has no value on record, so you can fill the gap before sending.
</Note>

</Tip>
